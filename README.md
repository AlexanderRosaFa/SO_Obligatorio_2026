# SO_Obligatorio_2026

## A Realizar

Primer Avance 
Para el primer avance, deben entregar por escrito: 

• Una descripción en lenguaje natural del problema desde el punto de vista funcional. \n
• Una identificación preliminar de los recursos y procesos o hilos involucrados en la solución. \n 
• Una descripción de los distintos criterios de optimización que podrían usarse. \n
• Una identificación preliminar de las zonas objetivo a considerar y de cómo podría 
modelarse su criticidad. \n
• Una explicación preliminar de cómo se definirá la prioridad de atención a partir de criticidad 
y urgencia. \n
• Un ordenamiento justificado de los criterios y una selección de los primeros que el equipo 
decida optimizar. \n
